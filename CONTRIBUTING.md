# Contributing

Thank you for helping make family-cookbook better.

## Issues are welcome

Open an issue at <https://github.com/scanady/family-cookbook/issues> for a bug,
a confusing message or doc, a printing problem, or an idea.

For a bug, please include:

- the engine version (`cookbook --version`);
- your operating system and Python version (`python --version`);
- the command you ran, and its full output;
- for a layout or printing problem, the page number and a screenshot of the
  page in `draft/cookbook-draft.html`; for a spine mismatch, the page count and
  the spine width from Lulu's cover template.

Share your book's recipes or files only if you are comfortable doing so. A
small made-up recipe that shows the problem is just as useful.

## No pull requests for now

Pull requests are not accepted at the moment, because the engine is also
offered under commercial licenses and every line in it needs a single clear
owner. If you have a fix, describe it in an issue; code in the issue is
welcome as an illustration.
